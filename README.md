Entry for the [make.fun](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) bounty **"The Funniest Honest Appliance Error"** — one line, at most 200 characters: the funniest honest error message an appliance could show.

## The entry

> ERROR E-11: Unbalanced load. One sock. I have spun it 47 times and it is still alone in there.

A washing machine, deadpan, telling the truth: an unbalanced load caused by a single sock — the one that lost its pair — and the machine has counted the spins.

## How it works

`main.ts` (Node 22, TypeScript) writes the entry to `/output/entry.txt` and
fails loudly if the text breaks the gate (1–200 characters, not only
whitespace).

```sh
node main.ts
```
